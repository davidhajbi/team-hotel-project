# Q2C Travel Landing Page

A Vercel-ready Next.js landing page for Q2C Travel — an AI quote-to-close sales operating layer for travel agencies.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

1. Import this GitHub repository into Vercel.
2. Framework preset: `Next.js`.
3. Build command: `npm run build`.
4. Output directory: leave default.
5. Deploy.

## Positioning

Q2C Travel helps travel agencies transform customer inquiries into structured, profitable and followed-up travel offers — from quote to payment, booking and post-booking optimization.
